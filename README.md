# Team of Silicons — www

SolidJS site for Team of Silicons: the home page, `/products` and `/writings`.

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # client + SSR build, then prerenders every route into dist/
npm run preview    # serve dist/
npm run typecheck
```

See `AGENTS.md` for how the pieces fit together.
